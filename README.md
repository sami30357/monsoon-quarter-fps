Monsoon Quarter — a three.js tactical FPS for the make.fun threejs-fps-02 bounty. A rain-slicked neon night market at dusk: bots that see and hear, bomb plant/defuse, round economy and a buy menu, grenades, headshots, and a sound/noise system where running is loud and crouching is quiet.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
